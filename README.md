## Federated Learning – Experimental Implementation

A simplified Federated Learning implementation built from scratch using Python and PyTorch. The project simulates multiple clients training a CNN on CIFAR-10 under different levels of non-IID label skew.

It implements Federated Averaging (FedAvg) and compares three learning-rate strategies: a fixed baseline, Local Adaptation (LA), and Server-Guided Adaptation (SGA).

This project was developed as a standalone experimental implementation to explore Federated Learning concepts. It is separate from the implementation used in my bachelor's thesis and does not reproduce its reported results.
